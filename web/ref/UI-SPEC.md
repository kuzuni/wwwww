# 원본 포지마스터 UI 스펙 (사용자 제공 스크린샷 20장 분석, 2026-08-16)

클라우드 세션 지침: 이 문서가 UI/시스템의 **단일 기준**이다. 기존 구현과 다르면 이 문서에 맞춰 고친다.
전체 톤: 흰 배경 팝업 카드(둥근 모서리, 굵은 검정 외곽선 느낌의 플랫 카툰), 파란 주요 버튼, 빨간 X 닫기 버튼(팝업 하단 중앙), 회색 비활성 버튼.

## 공통 레이아웃
- **상단바**: 좌측 프로필 카드(아바타+닉네임+⚔️전투력 20.7b), 우측에 👑코인 782k(+버튼), ◆젬 62(+버튼). 코인=주황 왕관 아이콘, 젬=빨간 다이아.
- **스테이지 라벨**: 상단 중앙 "어려움 4-1" + 진행 점(●─○). 난이도 접두어(쉬움/보통/어려움 등)+챕터-스테이지.
- **하단 탭 5개** (좌→우): 💀던전 / 🚪방(장비·제작?) / 🧪소환(스킬·펫·기술트리) / 🚩전투(PvP 리그) / 🏪상점. 열린 팝업에선 해당 탭이 빨간 X로 바뀜.
- 팝업 열기 = 전체화면 흰 카드, 닫기 = 하단 중앙 빨간 X 원형 버튼.

## 1. 메인 게임 화면
- 2D 사이드뷰 카툰 맵: 위아래 초록 숲(나무 다수), 중앙 가로 흙길, 캐릭터가 길 위를 오른쪽으로 진행.
- 길 위 이정표: 좌측 "1일 4시"(리그 보상), 우측 "1일 16시"(? 상자), 진행 패스 검 아이콘 등 이벤트 오브젝트가 맵에 배치됨.
- 우중단: 스킬 슬롯 — 초록 "자동" 토글 + 검은 원형 스킬 버튼 3개 (가로).
- 하단 시트(전투 화면 위에 항상 표시):
  - **장비 그리드**: 5열×2행 카드. 각 카드 = 아이콘 + "Lv.107" + 등급 별. 마지막 칸은 부화 중인 알(파란 배경, 게 아이콘 Lv.47처럼 펫도 섞임).
  - 그 아래: **모루(대장간) 그림 = 장비 뽑기(제작) 버튼** — 모루를 탭하면 해머 소모하고 장비 제작. 모루 아래 보유 해머 수(🔨41307) 표시. 옆에 [대장간 레벨 29] 파란 버튼(업그레이드) + [자동🔄] 파란 버튼(오토 포지 토글), "4일 2시"(업그레이드 남은 시간).
  - 최하단: 채팅 피드 1줄 (닉네임: 메시지, 말풍선 아이콘 99).
- 오프라인 보상 버튼: 화면 왼쪽 상단 영역 (현재 클론 배치 유지 OK).

## 2. 오프라인 보상 팝업
- 상단 검은 영역: "오프라인 보상" 타이틀, "수집 시간: 2시 10분"(초록), 아이콘 2개 — 👑 1.13/초, 🔨 1.14/분.
- 하단 흰 영역: 합계 "👑 8.87k 🔨 149.05", 큰 파란 [수집] 버튼, 아래 빨간 X.

## 3~5. PvP 리그 (전투 탭)
- **리그 화면**: 방패 엠블럼 + "플래티넘 리그", "시즌 종료: 1일 4시" + 🎁. 랭킹 리스트(순위, 아바타, 닉네임, ⚔️전투력, ⭐점수 84, 서버 8). 내 순위 행은 파란 하이라이트 + 화면 하단에 고정 반복 표시. 하단 [도전] 파란 버튼.
- **리그 보상 팝업**: "현재 순위(8)를 유지하면 시즌 종료 시 다음 보상" + 재화 6종(해머/코인/티켓/알/물약/태엽) 수량. 아래 순위별 보상 테이블(1위/2위/3위/4-5위/...) 스크롤. "수집까지: 1일 4시".
- **상대 선택 팝업**: "도전 티켓은 매일 09:00에 보충됩니다!" + 티켓 게이지 0/5(파란 티켓). 상대 5명 리스트(아바타, 닉네임, 전투력, ⭐+5~+1, [도전 🎫1] 버튼). 위쪽 상대일수록 강하고 ⭐보상 큼.
- 클론 구현: 상대는 봇(가짜 닉네임+전투력 랜덤 생성, 서버 불필요), 전투는 전투력 비교+약간의 랜덤으로 승패 판정, 시즌 3일 주기 보상 지급.

## 6~7. 던전 팝업 (던전 탭)
- "던전" 타이틀 + "던전 열쇠는 매일 09:00에 보충됩니다. 열쇠는 던전을 **완료할 때만** 소모됩니다".
- 가로 배너 4개 (각각 일러스트 배경): 🔨망치 도둑 / 🎫유령 마을 / 🥚침략 / 🧪좀비 러시. 각 배너 우측: 🔑 0/2 + [열기] 파란 버튼.
- **던전 상세 팝업**: 배너 이미지 + "난이도 20-9" (◀▶ 좌우 화살표로 도전 단계 선택 — 최고클리어+1이 기본, 이하 선택 가능) + "보상: 🔨302 👑27.1k" + 🔑0/2 + [이전 스테이지 소탕] [입장] 버튼.
- ❗현재 클론과 차이: 열쇠 소모 시점(입장→완료로 변경), 리셋 시각(자정→09:00), 난이도 선택 UI, 던전 팝업이 탭(전투화면 버튼 아님).

## 8, 11, 14. 스킬 (소환 탭 내 서브탭)
- 소환 탭 팝업 하단에 서브탭 3개: [스킬] [펫] [기술 트리].
- **스킬 화면**: 좌상단 티켓 게이지(🎫44). 타이틀 "스킬 15/18". 그 아래 합계 패시브 배너: "+9.13m 기본 피해 +73m 기본 체력".
- 스킬 그리드 5열×~4행: 원형 아이콘 + "Lv.64" + 등급 별 + 조각 게이지 "6/8". 장착된 스킬은 "장착됨" 리본.
- 하단: "장착됨" 행(장착 스킬 3개 아이콘+레벨), [모두 업그레이드] [빠른 장착] 버튼.
- 최하단: [소환 x5 🎫160] 큰 버튼 + x5 토글 + 소환 레벨 "Lv. 53" + 게이지 "5/110" + ℹ️(확률 팝업).
- **스킬 상세 팝업**: "[일반] 화살" + Lv.61 + 조각 1/8 + 설명 "화살의 폭발을 불러와 각각 **7.12k의 피해**를 줍니다" (— 스킬은 고정 데미지!) + "패시브: +4.13k 기본 피해 +33k 기본 체력" + [업그레이드](조각 부족 시 회색) [장착] 버튼.
- 업그레이드 = 중복 획득으로 모은 조각 N/8 소모 → 레벨업(레벨 오를수록 필요 조각 증가: 1/2→N/3→N/6→N/8...).
- **소환 확률 팝업(공용)**: "레벨 69 / 소환 확률" + ◀▶ + 등급별 색 막대(일반 15%/희귀한 15%/서사시 15%/전설 32.99%/궁극의 22.01%/신화 0%) + 하단 소환 경험치 게이지 20/23. 등급 한글명: 일반/희귀한/서사시/전설/궁극의/신화 (색: 회/파/초/노/빨/보).

## 9, 12, 13. 펫 (소환 탭 내 서브탭)
- **펫 화면**: 좌상단 🥚알 게이지(28), 우상단 젬. 펫 그리드: 보유 펫(사각 아이콘+장착됨 리본+Lv) + 미부화 알들("알" 표시).
- 하단: "장착됨" 행(펫 3개), [소환 x1 🥚100] 버튼(알 100개 소모), 소환 레벨 Lv.69 + 20/23 게이지 + ℹ️.
- 최하단 부화장: 슬롯 3개(알 + "8시 27분" 타이머), [슬롯+1 ◆400] 젬 구매.
- **펫 상세 팝업**: "[궁극의] 트렌트" + 장착됨 Lv.6 + "24m 피해 / 558m 체력"(고정 스탯) + 옵션 2줄 "+10% 치명타 확률 / +16.9% 더블 찬스" + [업그레이드] [제거/장착] 버튼.
- **펫 업그레이드 팝업**: 상단 대상 펫 카드 + 경험치 바 "87988/796140" + "합칠 펫 선택" + 보유 펫/알 목록에서 재료 선택(선택 슬롯 5칸) + [업그레이드] — 재료 펫/알을 경험치로 흡수해 레벨업.
- ❗펫은 전투에서 공격하지 않음. 장착 효과 = 고정 피해/체력 + 옵션 2개.

## 10, 15, 16. 기술 트리 (소환 탭 내 서브탭)
- **개요 화면**: 좌상단 🧪물약 40.1k + 🧫추가재화 18. 카드 4개: [대장간 68.7%] [힘 28.6%] [스킬, 펫 & 기술 38.8% (13시 32분)] [ANIMALS 1.69%] — 각 분기 진행률%, 연구 중이면 남은 시간 표시.
- **분기 상세**: 세로 노드 트리(위→아래로 진행, 좌우 분기 갈래). 노드 = 원형 아이콘 + "1/5". 완료 노드는 갈색/브론즈, 미해금은 흰색. 연구 중 노드 아래 남은 시간 배지 "13시 30분".
- **노드 팝업**: "추가 알 획득 기회 IV" + "추가 알 소환 기회 +2% (+2%)" + "연구 진행 중" 시간 바 "13시 30분" + [건너뛰기 ◆112] [취소].
- ❗연구는 **물약 소모 + 실시간 시간 소요**(대장간 업그레이드처럼), 젬으로 스킵. 노드당 5회.

## 17. 상점 팝업 (상점 탭)
- "오늘의 특가": 일일 상품 3개 (기술 거래=물약150+해머300+젬10 ₩2,800 / 펫 거래=알660+... ₩9,500 / 탈것 거래=태엽2.15k+... ₩69,000) — 클론에서는 현금 대신 [무료 수령 1회/일] 또는 광고 버튼 더미로.
- "보석": 젬 패키지 3개 (60/220/800 ◆).
- 클론: 결제는 더미 버튼(토스트 "데모 버전"), 배치만 동일하게.

## 18. 진행 패스 팝업
- "진행 패스" + 검 아이콘. 무료/프리미엄 2열 세로 트랙, 스테이지 도달("어려움 3-1" 등)마다 보상 칸(무료=회색+체크, 프리미엄=자물쇠). 프리미엄 ₩13,900 (클론: 더미).

## 19~20. 프로필/설정 팝업
- 프로필: 아바타(연필 편집), 이름, 성별, [파워 랭킹] [클랜 랭킹] 버튼, 하단 [프로필]/[설정] 토글.
- 설정: "서버 시간: 15. 8월, 19:27" + 토글 리스트(진동/음악/사운드 효과/채팅 표시/채팅 다크 모드/클랜 채팅 미리보기) + 언어/계정/차단 목록/개인정보 보호. 클론: 음악/사운드 토글만 실동작, 나머지 더미.

## 21~24. 대장간 팝업들 (추가 스크린샷)
- **확률 정보 팝업** ([대장간 레벨 29] 버튼 클릭 시): "확률 정보 / 제련 확률" 타이틀 + 우상단 ⓘ. "레벨 29 ▶ 레벨 30" — 시대 10종 색 막대 리스트, 각 행 = 시대 아이콘+이름+별 / 현재 레벨 확률% / 다음 레벨 확률% (두 열 비교). 시대 색: 원시적=회백, 중세의=하늘, 근대 초기=초록, 현대의=노랑, 우주=빨강, 항성간=보라, 다중 우주=청록, 양자=남색, 지하 세계=적갈, 신성한=주황. 하단 "업그레이드 진행 중…" 시간 바(4일 2시) + [건너뛰기 ◆815]. 업그레이드 시작/스킵이 이 팝업에서 이뤄짐.
- **모든 장비의 목록** (ⓘ 클릭): 시대별 섹션 헤더(색 막대 + 시대명 + 별 + 합계%) 아래 해당 시대 장비 아이콘 그리드(부위별 전부), 아이콘마다 개별 획득 확률(0.0000%).
- **장비 상세 팝업** (목록에서 아이템 클릭): "[원시적] 가죽 / 2k 체력" + 안내문 "장비은(는) 아래 목록에서 2x개의 고유한 하위 스탯을 굴립니다:" + **서브스탯 풀 13종** (장비·펫·탈것 옵션 공용 풀):
  - +1%~12% 치명타 확률 / +1%~80% 치명타 피해 / +1%~5% 블록 확률 / +1%~4% 체력 재생 / +1%~20% 생명력 흡수 / +1%~20% 더블 찬스 / +1%~15% 피해 / +1%~50% 근접 피해 / +1%~15% 원거리 피해 / +1%~40% 공격 속도 / +1%~30% 스킬 피해 / -1%~-7% 스킬 재사용 대기시간 / +1%~15% 체력
- **자동 제련 팝업** ([자동🔄] 버튼 클릭): ① "유지" — 시대 체크리스트(고티어 5개 표시, 체크한 시대 장비만 유지/장착 후보) ② "필터" 토글 — 켜면 아래에 서브스탯 체크리스트 표시(원하는 옵션 필터), **끄면 체크리스트가 숨겨지고 빈 공간** (시대 체크만으로 동작) ③ "한 번에 사용된 망치 수" 스피너 — **1~22 범위** ④ "목표 장비를 찾으면 제련 계속하기" 체크박스 ⑤ [시작] 파란 버튼. 일반 제작도 망치 1~22개 배치 소모 방식.

## 25. 장비 비교 팝업 (제작/드랍 시) — 사용자 확정 레이아웃
- 전투 화면 위에 뜨는 흰 카드 팝업. **위 = "장착됨" 리본 + 장착 중인 장비 카드**, **아래 = 새 장비 카드** (아이콘 아래 "새로운!" 빨간 라벨).
- 카드 구성: 좌측 큰 아이콘(등급색 배경 + "Lv. 107" + ⭐승천 별) / 우측 "[시대] 이름"(시대색 텍스트) + "53.6m 피해" 주 스탯 + 비교 화살표(▲초록=상승/▼빨강=하락) + 옵션 줄들("+18.2% 더블 찬스" 등).
- 하단 버튼: 좌 빨강 [판매] / 우 파랑 [장착]. (현재 클론은 새 장비가 위 — 이 스펙대로 순서 교체)

## 26. 장비 세부정보 팝업 (메인 화면 장비 그리드 카드 클릭 시)
- 작은 흰 카드 팝업 (비교 팝업과 같은 카드 스타일, 버튼 없음): "장착됨" 리본 + 좌측 아이콘(등급색 배경, Lv, ⭐) + "[시대] 이름" + 주 스탯("432m 체력") + 옵션 줄들. 바깥 탭하면 닫힘.

## 27. 플레이어 정보 팝업 (메인 화면 **왼쪽 하단 "!" 버튼** 클릭 시)
- 상단: 아바타 + 닉네임 + [클랜명] + 성별/서버 아이콘 + ⚔️전투력(주황) / 우측 정렬: "Lv. 29 대장간 ⭐" + "588m 총 피해" + "3.75b 총 체력".
- 그 아래: 현재 전투 장면 미니 프리뷰(가로 스트립).
- 장착 장비 그리드 5×2 (카드: 아이콘+Lv+⭐).
- 장착 스킬·펫 행 (작은 원형 아이콘 + Lv).
- 하단: **옵션 합계 리스트** — 장비+펫+스킬 모든 서브스탯 합산 표시 ("+44.4% 치명타 확률 / +276% 치명타 피해 / +3.67% 체력 재생 / +21.5% 생명력 흡수 / +57.4% 더블 찬스 / +3.86% 피해 / +22.8% 원거리 피해 …" — 보유한 옵션 전부, 스크롤).

## 28. 채팅 화면 (메인 하단 채팅 피드 탭 시 전체화면)
- 검은 배경 세로 스크롤 메시지 리스트. 메시지 행 = 좌측 아바타(흰 사각 카드) + "[클랜태그] 닉네임"(주황/초록 등 색) + 성별·배지 아이콘 + 우측 타임스탬프(03:39) + 아래 회색 말풍선(둥근 사각) 메시지.
- 특수 메시지: **전투 공유 카드** — "N이(가) 전투를 공유했습니다" 후 카드(좌 초록 "승리" + 승자 아바타·닉네임·⚔️전투력 / 우 회색 패자) + 📹 아이콘.
- 하단 고정: 빨간 ◀ 뒤로 버튼 + "메시지 보내기..." 입력 바.
- 클론 구현: 봇 채팅(가짜 닉네임·클랜태그 풀에서 주기적으로 한담 생성, 영어/한국어 섞기), 내 메시지는 입력 시 즉시 표시(로컬), 내 리그 전투 결과를 공유 카드로 자동 게시. 메인 화면 하단 1줄 피드 = 최신 메시지 미리보기, 탭하면 이 화면.

## 승천(별) 시스템 — 사용자 확정 (2026-08-16)
- 승천은 게임 전체 프레스티지가 아니라 **개별 단위**: 장비, 스킬, 펫, 탈것이 **각각 따로** 승천한다.
- 승천 1회 = 해당 대상에 ⭐ 별 1개 추가. **별 개수 = 그 대상의 승천 횟수.** (스크린샷의 카드마다 붙은 별이 이것)
- 별이 붙으면 해당 대상의 능력치가 크게 상승(원본 커브 미확보 → 회당 ×2 근사 등으로 설계, 웹 검색 참고).
- 승천 조건(레벨 상한 도달 등)은 원본 확인 필요 — 미확보 시: 스킬=만렙 조각 초과분, 펫/탈것=만렙 후 합성, 장비=동일 장비 재획득 등으로 근사.
- 기존에 구현된 "전체 리셋형 승천"은 이 스펙으로 대체한다.
