# Voxel 폴리싱 루프 기준서 (기능 TODO 소진 후 자동 진입)

목표: web/ 게임의 비주얼·연출 퀄리티를 **고퀄 프리미엄 voxel 게임** 수준으로. "괜찮은데?"는 실패. 비평가가 감탄해야 통과.

> 🧊 **화풍 = Voxel + 치비 귀여움 (사용자 최종 확정 2026-08-20).** 이 문서의 옛 '원신급/AAA 사실주의' 기준은 **전부 폐기**됐다. 상세·확정 근거는 `web/TODO.md` '그래픽/연출 품질 기준' 섹션 최상단 🧊 블록이 정본이고, 이 문서는 그에 종속된다.

**⚠️ 기준 구분 (중요)**:
- **UI 배치**만 원본 포지마스터 스크린샷(web/ref/screens)을 따른다 — 레이아웃 충실도 기준.
- **그래픽 퀄리티는 원본(2D 플랫)과 다른 축이다.** 이 클론의 목표는 **고퀄 큐브 기반 voxel**(크로시로드·로블록스·마인크래프트 던전·Teardown급)이다.
- **기준점 = 고퀄 Voxel 게임 (원신 아님 — 2026-08-20 폐기).** 비평가 채점 질문: **"이 스크린샷/연출을 크로시로드·Teardown 같은 완성도 높은 프리미엄 voxel 게임의 한 장면이라고 믿을 수 있는가?"** — 큐브 조형의 명료한 실루엣, 치비 매력(큰 머리·큰 눈·둥근 큐브), **큐브 이음새 AO**·부드러운 그림자·림라이트, 풍부한 팔레트와 큐브별 미세 색변화, 블룸/컬러그레이딩/비네트, 이미시브 큐브(발광), 청키하지만 시원한 큐브 이펙트, 찰진 파츠 애니(스쿼시&스트레치·바운스)를 voxel 레퍼런스로 평가한다. 각 영역 10점 만점, **9점 이상만 통과**. 기술 제약(three.js r128, 절차 생성)은 voxel엔 **족쇄가 아니라 정답**이다(코드 큐브 = 진짜 voxel 아트, 근사 갭 0) — 낮은 점수의 면죄부가 될 수 없다.
- **연출(모션·이펙트·시네마틱)도 voxel풍 과장.** 스킬 발동·보스 등장·사망·타격·전환·보상 연출은 정지 화면이 아니라 **연속 프레임 캡처(0.1초 간격 이상 촘촘히)**로 타이밍·이징·파츠 애니 생동감(큐브 스쿼시&스트레치·청키 파티클)을 평가한다. 한 장짜리 스크린샷 통과 금지.

1. **지형/배경** — 지형 셰이딩, 하늘 그라데이션, 안개 깊이감, 원경 실루엣, 챕터별 분위기 차별화

3. **전투 이펙트** — 타격감(히트스톱·플래시), 파티클, 무기 트레일, 카메라 쉐이크 완급, 처치 연출
4. **캐릭터/몬스터** — 모션 보간, 스쿼시&스트레치, 등장/사망 연출, 대기 모션 생동감
5. **UI/HUD** — 마이크로 인터랙션(버튼 눌림·팝업 스프링), 전환 애니메이션, 타이포·아이콘 일관성, 숫자 카운트업
6. **사운드** — 타격/보상/UI 사운드 타격감, 레이어링, 음량 밸런스

## 루프 프로토콜 (영역당)
1. 개선 구현 (아래 기술 제약 준수)
2. **혹독한 비평가 검증**: Playwright로 해당 영역이 드러나는 실제 스크린샷 3장 이상 촬영.
   서브에이전트(Task)를 쓸 수 있으면 비평가를 별도 에이전트로 분리하고, 없으면 스스로 역할을 바꿔 최대한 가혹하게 평가.
   - 영역 ①~④·⑥ (그래픽/연출/사운드): **고퀄 voxel 기준 10점 채점** — "완성도 높은 프리미엄 voxel 게임(크로시로드·Teardown) 스크린샷이라고 믿을 수 있는가?" 9점 미만이면 실패. 구체적 결함 목록(큐브 조형·AO·라이팅·색·타이밍·파츠 애니)을 남길 것.
   - 영역 ⑤ (UI/HUD): 배치는 원본 스크린샷과 블라인드 비교(레이아웃 충실도) + 마감 퀄리티는 voxel 기준 10점 채점 병행.
3. 통과 기준 충족 시 → 커밋·푸시 → 다음 영역. 실패면 결함 목록 기반으로 1번 반복.
4. 영역당 한 세션에서 3회 반복해도 통과 못 하면, 결함 목록을 이 파일 하단 '진행 로그'에 기록하고 커밋 — 다음 세션이 이어받는다.

## 기술 제약 (절대)
- three.js r128 클래식 스크립트, file:// 실행, 외부 CDN·에셋 파일·웹폰트 금지
- 텍스처는 전부 절차적 생성(캔버스/셰이더), 커스텀 ShaderMaterial 적극 사용
- 파티클·소품은 인스턴싱(InstancedMesh)으로 성능 확보
- 모바일 세로 9:16, 중급 폰 기준 60fps 유지 — 이펙트 추가 후 반드시 프레임 확인
- **게임 로직·밸런스·저장 데이터는 건드리지 않는다.** 보이는 것/들리는 것/느껴지는 것만.
