# HP 타격감 채점 산출물 (3D 스트림)

`node tools/shot-hpjuice.js && node tools/compose-hpjuice.js` 로 전부 재생성된다.

여기 커밋해 둔 것은 **판정 근거로 남길 최소한**이다:
- `*.json` — 프레임별 실측 telemetry. `fg`=앞바 비율, `ghost`=잔상바 비율,
  `hitStop`=남은 히트스톱(초), `vig`/`vigOn`=비네트 세기·on 여부, `clock`=연출시계(초),
  `ms`=실시간 경과, `barY`=머리 위 바의 화면 y(크롭이 바를 자르는지 확인용).
- `strip-A-crit-bar.png` — 적 2단 HP바 3배 확대. 앞바(민트)/잔상바(주황)/빈 구간(어두운 슬레이트)이
  프레임마다 분리돼 읽히는지 보는 용도.
- `strip-D-hero-bar.png` — 영웅 머리 위 바 같은 확대.

**원본 프레임 90장과 나머지 스트립 8장은 커밋하지 않는다** (합쳐 19MB, 스크립트로 즉시 재생성됨).
이 저장소는 GLB 임베드 29MB를 걷어낸 이력이 있어 재생성 가능한 캡처물을 그대로 쌓지 않는다.
