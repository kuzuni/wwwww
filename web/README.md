# 포지 클론 (Forge Master Clone)

HTML + Three.js로 만든 9:16 세로형 방치 RPG. 밸런스 수치는 원본 포지마스터 실측 테이블(`data/raw/`, `js/balance-data.js`) 그대로 사용.

## 실행

`index.html`을 브라우저에서 열면 끝 (서버 불필요, 모든 리소스 로컬).

## 구현된 시스템

- **3D 자동 전투**: 웨이브 4 + 보스 1 구조, 돌진 공격/치명타/넉백/파티클/카메라 셰이크/데미지 숫자, 챕터별 배경 테마 10종
- **대장간**: 원본 업그레이드 비용·시간 테이블(Lv1~35), 원본 시대 티어 확률표(원시~디바인 10시대), 실시간 타이머(꺼도 진행), 젬 스킵, 오토 포지(2-10 해금)
- **장비 8부위**: 무기/투구/갑옷은 3D 외형 반영(페이퍼돌), 등급 6단계, 서브스탯, 판매가 원본 공식 `20×1.01^(Lv-1)`
- **펫**: 원본 알 드랍 확률표(1-1~10-10), 원본 부화 시간(30분~32시간), 원본 펫 스탯 25종, 출전 3마리 전투 참여, 중복 레벨업, 합성
- **스킬**: 원본 소환 확률표(소환 Lv1~100), 18종(광역/단일/회복/버프), 자동/수동 시전, 4슬롯 장착, 중복 레벨업
- **오프라인 보상**: 원본 수급률(코인 1/초, 해머 1/분, 캡 4시간)
- **저장**: localStorage 자동 저장(30초 + 탭 이탈 시), 타이머는 절대시각 저장

## 파일 구조

```
index.html          진입점
css/style.css       9:16 레터박스 + rem 스케일 UI
js/
  balance-data.js   원본 밸런스 테이블 (자동 생성)
  gamedata.js       정적 정의 (시대/등급/장비명/스킬/펫 비주얼)
  state.js          상태/저장/오프라인
  forge.js          제작·장비·업그레이드
  pets.js           알·부화·합성
  skills.js         소환·레벨
  combat.js         전투 틱 엔진 (100ms 고정 틱)
  scene3d.js        Three.js 씬 + 연출
  ui.js             패널/HUD/모달
  main.js           부트스트랩 + 루프
lib/three.min.js    Three.js r128 (로컬)
data/raw/           원본 추출 데이터 (출처: github.com/1vcian/ForgeMasterCalculator)
```
